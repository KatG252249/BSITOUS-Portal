# BSIT OUS Student Portal

A centralized digital hub designed for distance learners enrolled in the Bachelor of Science in Information Technology (BSIT) program at the Polytechnic University of the Philippines – Open University System (PUP OUS).

## 🌐 Live Demo

Visit the portal here: [BSIT OUS Student Portal](https://katg252249.github.io/BSITOUS-Portal/)

## 📌 Features

- **Quick Access Dashboard**: Centralized navigation for academic dates, subject offerings, advisories, downloadable forms, and consultations.
- **Academic Calendar & Key Milestones**: Real-time visibility on critical academic schedules, such as semester openings and adjustment periods.
- **Curriculum & Course Information**: Reference guides for course codes, prerequisites, and full year-level requirements.
- **Student Services & Form Hub**: Easy access to administrative forms (ACE forms, overloading requests, bridging evaluations, and OJT requirements).
- **Direct Consultations**: Quick-booking interface for academic advising and Program Chair sign-offs.
- **Announcements & Publications**: Latest department bulletins and access to The Source Code organizational newsletter.
- **Institutional Portals Directory**: Direct gateways to PUP Main, PUP OUS, PUP SIS, and the eMabini learning management system.

## 🚀 Getting Started

### Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/katg252249/BSITOUS-Portal.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd BSITOUS-Portal
   ```

3. **Open the project:**
   - Open `index.html` directly in your browser, or run a local development server (e.g., VS Code Live Server).
